## Projetos
### Projeto 1: Sorteador de Números
Um aplicativo web para sortear números aleatórios, com funcionalidades de criação, edição e exclusão de listas de números.
- **Tecnologias:** HTML, CSS, JavaScript

### Projeto 2: Loja Online
Plataforma de e-commerce completa, permitindo aos usuários navegar por produtos, adicionar ao carrinho e finalizar compras.
- **Tecnologias:** React, Node.js, MongoDB

### Projeto 3: Análise de Dados
Aplicação para visualizar e analisar dados em tempo real com gráficos interativos e relatórios customizáveis.
- **Tecnologias:** Python, SQL, Data Visualization

### Projetos em Breve
- Projeto 4: Node.js, Express, JWT
- Projeto 5: React Native, Firebase
- Projeto 6: Vue.js, TypeScript, REST API
